This project combines a FastAPI backend, a polished browser experience, data-driven recommendations, and profile-aware workflows to simulate a realistic tech education platform.

Try the recommender

What this version includes

  • Interactive curriculum recommendation workflow
  • Profile persistence and personalized insight
  • Expanded course coverage for data, AI, cloud, web, and security paths
  • Modern multi-page frontend structure for a stronger student experience

Architecture

FastAPI powers the API layer, while the frontend is served as a polished static experience with local profile and saved-item support.

Recommendation logic

The ranking engine combines skill overlap, TF-IDF similarity when available, popularity weighting, and curriculum-level aggregation.

Future refinement

Next steps include richer authentication, richer course metadata, analytics dashboards, and a stronger database-backed profile system.
